## Prompt 1

Design a role-based project access control system
with Admin and Employee roles.

Admin can:
- create projects
- assign tasks

Employee can:
- view only assigned tasks
- update task status

Generate:
- system flow
- edge cases
- routing logic
- frontend architecture

### Why I used this prompt
To generate a complete system overview and identify
important business logic and edge cases.
